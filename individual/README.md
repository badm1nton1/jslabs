# Instrument Shop

## Авторы
Антовонич Богдан

## Описание
Веб-приложение для просмотра и управления каталогом музыкальных инструментов.

Функции:
- Просмотр списка инструментов в виде карточек
- Добавление нового инструмента через форму с валидацией
- Удаление инструмента
- Изменение статуса (в наличии / нет в наличии)
- Поиск по названию
- Фильтрация по типу инструмента (вкладки)
- Сортировка по цене или названию
- Модальное окно с деталями

## Установка и запуск

Зависимости не требуются.

### VS Code + Live Server
1. Открыть папку проекта в VS Code
2. Установить расширение Live Server
3. Нажать "Go Live" внизу редактора

### Node.js
```bash
npx serve .
```
Открыть http://localhost:3000

> Открывать index.html напрямую двойным кликом нельзя. ES6-модули требуют локальный сервер.

## Пример использования

Добавить инструмент:
- Name: Ibanez RG350
- Type: Guitar
- Price: 450
- Нажать "+ Add"

Результат: карточка появится в списке со статусом "In stock".

Поиск: введите "yamaha" — отобразятся только инструменты Yamaha.

Фильтрация: нажмите "Guitar" — останутся только гитары.

Сортировка: выберите "Price: low to high" — список выстроится по цене.

Кнопка "Mark Unavailable" переводит карточку в серый режим "Out of stock".

Кнопка "Details" открывает модальное окно. Закрыть — крестиком или кликом рядом.
